# Residual function analysis

The symbol pass translated every name retained in the original ARM64 ELF, and
the reviewed callback and role pass added names only where the address and
behavior were checked. The final IDA inventory still has 394 address-only
`sub_` functions. This is expected for code that IDA discovered inside static
libraries, compiler-generated cleanup paths, and fixed init or fini arrays.

The complete address list and coarse classification are in
`artifacts/ida_final_residual_audit_20260830.json`. That report places 120
functions in the embedded FreeType region, 150 in the embedded JPEG region,
19 in init or fini array support, 102 in static cleanup wrappers or other
support, and one AArch64 PLT resolver slot. The count is a property of this
IDA database and the original library hash, not a claim that all 394 routines
are application code.

Twenty-four routines formerly counted as residuals now have exact matches in
the tagged FreeType 2.3.6 source tree. The source file and line anchors, IDA
sizes, xref counts, and matching evidence are recorded in
`artifacts/ida_freetype_source_matches_20260901.json`.

## Reviewed high-reference routines

The active IDA database was used to inspect a representative set of the most
referenced remaining unnamed functions. The compact machine-readable record is
`artifacts/original_residual_semantic_review_20260830.json`, generated by
`tools/generate_original_residual_semantic_review.py`.

| Address | Size | References | Observed role |
| --- | ---: | ---: | --- |
| `0x256060` | 880 | 12 | Printable byte-string sanitizer |
| `0x2563d0` | 524 | 16 | Printable 16-bit string sanitizer |

The two remaining helpers are called from the FreeType internal routine at
`0x25a8e0`; their NEON loops normalize printable diagnostic text and append a
null terminator. The arithmetic, stream, identity, cleanup, and interpreter
handlers that were previously in this table are now named and documented by
the exact source-match artifact.

## Naming decision

The two diagnostic helpers remain named by address. The review establishes
their roles, but it does not establish an exact upstream source name. The
other 24 reviewed FreeType and TrueType routines were renamed only after the
tagged source body, callback-table or vtable context, and the current IDA
address all agreed. That distinction keeps source-backed names separate from
useful hypotheses.

This pass is also not a vulnerability report. The selected routines are
embedded library internals, and their presence alone does not show that an
attacker controls their inputs. The broader image, font, archive, and network
input reviews remain the relevant security boundaries.
